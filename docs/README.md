# LearnWhatYouOwn Documentation

This directory is the master source of truth for company vision, product strategy, architecture, design, legal, API, and investor materials.

All edits should be made through GitHub so the same version is available on every device.

## Sections

- `vision/` — mission, founder narrative, values, positioning, and roadmap
- `architecture/` — equity, AI, community, and data systems
- `product/` — MVP, features, personas, onboarding, and monetization
- `api/` — API specifications and integration notes
- `design/` — design system and user-experience documentation
- `legal/` — legal, compliance, privacy, and disclosure materials
- `investor/` — company narrative, pitch materials, and investor FAQ
